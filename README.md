
# CG-Porject2

This project contains different scene to demonstrate what could be created using OpenGL and C++.
There is Light computation, with standard and PBR Materials, there is a Physic simulator, a mesh normal vector viewer (used a lot to debug meshes), texture and imported mesh management.

## Instruction
 - `W` => move FORWARD
 - `S` => move BACKWARD
 - `A` => move LEFT
 - `D` => move RIGHT
 - `SPACE` => move camera UP
 - `LEFT_SHIFT` => move camera DOWN
 - `I` => go in interactive mode
 - `P` => go in passive mode
 - `MOUSE3` => in `NormalViewState` trackball mouse movement
 - `ESC` => close the program
